# 用户指南

[English](../user-guide.md) | **简体中文**

你照常使用 SSH 即可。GPU Ops 在后台完成计量与策略执行。

## 日常使用

```bash
ssh user@node05
python train.py
```

只要余额正常，你的工作流不会有任何变化。

## 账号状态

| 状态 | 含义 |
| --- | --- |
| `normal` | 完全可用 |
| `warning` | 余额偏低；已在运行的任务继续 |
| `limited` | shell 钩子拦截新的 GPU 任务；CPU 可能被限速 |
| `blocked` | 已欠费；GPU 被禁用，CPU 被大幅限速 |

若超出管理员设置的每月欠费上限，你的全部进程会被终止。

节点可能会在你的家目录写入状态文件：

| 文件 | 含义 |
| --- | --- |
| `~/.gpu_notice` | 来自平台的消息 |
| `~/.cpu_quota` | 当前对你生效的 CPU 限制 |
| `~/.gpu_blocked` | 你已被封禁；控制器不可达时，shell 钩子以此为准 |

## 积分

- **通用积分**按你的类别（博士、硕士、其他）或管理员的特殊规则每月发放。
- **结转积分**是上月未用完的通用积分，在月初结转，并受结转上限约束。该上限限制的是累计池，而不是每月新增量。
- **节点专属积分**只在指定节点可用，不结转，也不按月过期。

扣费顺序为 **节点专属 → 结转 → 通用**。

## shell 钩子

管理员可能会在你的 `~/.bashrc` 中加入：

```bash
source /opt/gpu-cluster/check_quota.sh
```

该钩子会包装 `python`、`python3` 和 `nvidia-smi`。当一条命令看起来会用到 GPU 时——脚本或 `-c` 片段中出现 `torch`、`tensorflow`、`jax`、`cuda`，或设置了 `CUDA_VISIBLE_DEVICES`——它会先查询你的余额。

它在拦截上刻意保守：

- 控制器有响应时，以控制器返回的状态为准。
- 控制器不可达时，只有本地存在 `~/.gpu_blocked` 才会拦截。

## 查询余额

Web 界面：**我的余额**，同时展示积分变动与用量历史。

若管理员已部署辅助工具，也可以在节点上执行：

```bash
CONTROLLER_URL=https://gpu-ops.example.org balance-query
```

余额接口需要凭据。在受管节点上，辅助工具从 `/etc/gpu-ops/query-token` 读取。若出现鉴权错误，请联系管理员部署该文件——这不是你自己能创建的。

## 注册与账号绑定

当集群对未登记账号拦截 SSH 时，你需要先注册才能登录：

1. 打开控制器 Web 界面，例如 `https://gpu-ops.example.org/`。
2. 进入 **用户 → 注册**。
3. 二选一：
   - **绑定已有账号** — 申报你已有账号的节点，以及在每个节点上的本地用户名。
   - **申请新账号** — 请管理员在你尚无账号的节点上开通。
4. 在 **我的申请** 中跟踪结果（`pending` / `approved` / `rejected`）。

注册可能被限定在特定邮箱域名，并可能需要邮箱验证。

## 密码

注册、重置与修改都要求强密码：

- 12–64 个字符
- 至少包含一个大写字母、一个小写字母、一个数字和一个特殊字符（例如 `!@#$%^&*_-+=`）
- 不能包含空格

你可以在个人资料中启用 TOTP 两步验证，管理员也可能强制要求。

## 常见问题

**能登录但跑不了 GPU 任务。** 你多半处于 `limited` 或 `blocked` 状态。请查看余额，并联系管理员充值。

**控制器不可达时我会被拦截吗？** 除非该节点上存在 `~/.gpu_blocked`，否则不会。如果你被拦截且认为不应该，请联系管理员。

**完全无法 SSH 登录。** 集群很可能拦截了未登记账号。请在 Web 界面提交绑定或开通申请，等待审核。

**我的任务被杀了。** 你的欠费超过了每月上限，或被管理员手动终止。用量历史会显示导致这一结果的扣费记录。

**CPU 限制突然出现。** 请查看 `~/.cpu_quota`。进入 `limited` 与 `blocked` 状态时会自动施加限制。
